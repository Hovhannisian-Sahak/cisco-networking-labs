# Cisco Networking Labs

A collection of hands-on networking labs built with Cisco Packet Tracer, progressing from basic device connectivity to IPv4 addressing, switching, routing, and device security.

## Lab catalog

| # | Lab | Project file |
|---:|---|---|
| 01 | Packet Tracer Introduction | [`Packet Tracer Introduction.pkt`](labs/01-packet-tracer-introduction/Packet%20Tracer%20Introduction.pkt) |
| 02 | Connecting Devices | `labs/02-connecting-devices/Connecting Devices.pkt` |
| 03 | OSI Model | `labs/03-osi-model/OSI Model.pkt` |
| 04 | IPv4 Addresses | `labs/04-ipv4-addresses/IPv4 Addresses.pkt` |
| 05 | Ethernet LAN Switching | `labs/05-ethernet-lan-switching/Ethernet LAN Switching.pkt` |
| 06 | Configuring Static Routes | `labs/06-static-routes/Configuring Static Routes.pkt` |
| 07 | Basic Device Security | `labs/07-basic-device-security/Basic Device Security.pkt` |

## Getting started

1. Install Cisco Packet Tracer.
2. Open a lab's `.pkt` file in Packet Tracer.
3. Inspect the topology and any instructions included in the project.
4. Complete the activities and verify the results in Packet Tracer.
5. Save a separate working copy before experimenting so the committed project stays unchanged.

## Documentation approach

This root README is the central index for all labs; individual lab README files are intentionally not used. Lab-specific topology, addressing, commands, and verification results can be added to each table entry once they have been confirmed in Packet Tracer.
