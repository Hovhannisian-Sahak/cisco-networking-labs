# Cisco Networking Labs

A hands-on networking portfolio built with Cisco Packet Tracer, progressing from basic device connectivity to IPv4 addressing, switching, routing, and device security.

## Lab catalog

The source archive contains the following seven Packet Tracer projects. The **Packet Tracer Introduction** project is currently published in this repository; the remaining projects should be added to their matching folders as they are published.

## Getting started

1. Install Cisco Packet Tracer.
2. Open a published `.pkt` project from its lab folder.
3. Read the corresponding lab notes and inspect the topology and instructions.
4. Complete the tasks and verify the results in Packet Tracer.
5. Save a separate working copy before experimenting, so the published project remains unchanged.

## Documentation standards

Each lab README should describe the verified objectives, topology, addressing, configuration steps, verification commands and observed results, and troubleshooting notes. Details should be added only after checking the actual project in Packet Tracer.
