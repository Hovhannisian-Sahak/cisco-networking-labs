# Cisco Networking Labs

A collection of hands-on networking labs created with Cisco Packet Tracer. Each lab includes its `.pkt` project file and notes for objectives, topology, configuration, verification, and troubleshooting.

## Labs

| Lab | Project file | Documentation |
|---|---|---|
| 01 — Packet Tracer Introduction | [`Packet Tracer Introduction.pkt`](labs/01-packet-tracer-introduction/Packet%20Tracer%20Introduction.pkt) | [Lab 01 README](labs/01-packet-tracer-introduction/README.md) |

## Getting started

1. Install Cisco Packet Tracer.
2. Open the `.pkt` file from the relevant lab folder.
3. Review the topology and lab notes before making changes.
4. Save a separate copy before experimenting so the committed baseline remains intact.
